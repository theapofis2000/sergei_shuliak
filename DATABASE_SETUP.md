# Подключение формы и статистики через Supabase

На сайте уже подготовлены форма обратной связи и статистика уникальных браузеров за сутки. Для записи данных нужен проект Supabase.

## Первоначальная настройка

1. Создайте проект в [Supabase](https://supabase.com/dashboard).
2. Откройте **SQL Editor**, вставьте содержимое `supabase/schema.sql` и выполните его.
   Если проект уже настроен, вместо повторного запуска базовой схемы выполните миграцию `supabase/unique_visitors.sql`.
3. В настройках проекта скопируйте **Project URL** и **Publishable key** (`sb_publishable_...`).
4. Вставьте их в `supabase-config.js` в поля `url` и `publishableKey`.
5. Опубликуйте обновлённые файлы сайта на GitHub Pages.

В браузерный файл разрешено помещать только **Publishable key**. Он виден посетителям сайта; безопасность обеспечивают права базы и функции из `schema.sql`. Не вставляйте сюда Secret key или старый `service_role` key.

## Где смотреть данные

- Сообщения: Supabase → **Table Editor** → `contact_messages`.
- Уникальные браузеры за день: Supabase → **Table Editor** → `daily_unique_visits`.
- Старый счётчик загрузок страницы: `daily_visits` (исторические данные; новая версия сайта его больше не увеличивает).

Браузер создаёт случайный ID для текущего дня и хранит его в `localStorage`. База учитывает этот ID один раз за UTC-день, поэтому повторные загрузки не увеличивают число. На следующий день ID меняется. IP-адрес, имя и email не включаются в данные RPC и не сохраняются в таблицах статистики. Как и любой сетевой сервис, инфраструктура может отдельно обрабатывать технические данные соединения. Таблица с дневными ID закрыта от чтения через публичный API и очищается от старых дат при следующем посещении.

Это счётчик браузеров, а не точных людей: другой браузер или очистка хранилища создаст новый ID, а автоматические запросы всё ещё могут влиять на результат. Форма имеет скрытое поле-ловушку и серверную проверку значений; при появлении спама можно добавить CAPTCHA и ограничение частоты отправки.

## Уведомления на электронную почту

Для уведомлений о новых сообщениях и первых уникальных посещениях за день используйте инструкцию из `EMAIL_NOTIFICATIONS_SETUP.md`. Письма отправляются Google Apps Script по вызову из триггеров Supabase; URL и общий секрет хранятся в Supabase Vault, а секрет сайта не попадает в браузерный код или Git.
